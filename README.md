# 🩺 Medical Data Visualizer

## 📌 Description

This project is part of the **freeCodeCamp Data Analysis with Python Certification**.
It analyzes medical examination data and visualizes the relationship between lifestyle habits, body measurements, and cardiovascular disease using Python.

---

## 🛠 Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* NumPy

## 🔍 Features Implemented

* BMI calculation and overweight classification
* Data normalization (cholesterol and glucose)
* Categorical data visualization
* Data cleaning using percentiles
* Correlation matrix and heatmap
